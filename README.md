# Crop Yield Prediction using Machine Learning

## 📌 Overview
This project predicts crop yield using Machine Learning techniques based on various agricultural and environmental factors such as rainfall, temperature, soil conditions, and other related features.

The project was developed and executed using Google Colab with data preprocessing, visualization, model training, and evaluation.

---

## 🚀 Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Correlation heatmap visualization
- Feature engineering
- Machine Learning model training
- Model evaluation using:
  - MAE
  - MSE
  - RMSE
  - R² Score
- K-Fold Cross Validation
- Prediction analysis

---
